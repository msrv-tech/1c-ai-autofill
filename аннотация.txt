Аннотация
Название программного продукта: «MSRV.tech: Интеграция с нейросетью для заполнения описаний. Расширение для 1С:Предприятие», редакция 1.0 Разработчик: ООО “МАНЖЕЛА” Категория: Расширение к конфигурации.
Отрасли: Интернет-магазины
Описание: Продукт предназначен для владельцев интернет-магазинов, каталогов товаров и продавцов на маркетплейсах. Позволяет генерировать продающие описания номенклатуры и автозаполнять дополнительные реквизиты и характеристики с помощью ИИ через API сервиса Gitsell (без необходимости использования VPN). Поддерживаются модели Gemini, GigaChat, YandexGPT, OpenAI, Deepseek и другие. Имеется возможность использования собственного OpenAI-совместимого провайдера и редактирования промпта для генерации.
Основные функциональные возможности: • Генерация продающего описания товара по наименованию номенклатуры одной кнопкой из карточки. • Автозаполнение дополнительных реквизитов и характеристик номенклатуры с помощью выбранной модели ИИ. • Настройка API-токена и выбор модели ИИ (в т.ч. Gitsell) в карточке номенклатуры. • Возможность использования собственного OpenAI-совместимого провайдера. • Редактирование промпта для настройки генерации описаний под задачи пользователя. • Работа без VPN; возможность бесплатного тестового периода (в соответствии с условиями сервиса).
Расширение «MSRV.tech: Интеграция с нейросетью для заполнения описаний. Расширение для 1С:Предприятие» разработано для конфигураций: «Управление нашей фирмой» (УНФ), «1С:Розница», «Управление торговлей 11» (УТ11), «Комплексная автоматизация» (КА), «1С:ERP Управление предприятием» — для актуальных редакций на управляемых формах. Расширение имеет назначение Дополнение и не требует внесения изменений в типовую конфигурацию. Рекомендованная к использованию версия платформы «1С:Предприятие 8.3» определяется требованиями расширяемой типовой конфигурации (версии не ниже 8.3). При смене релиза типовой расширяемой конфигурации, при необходимости, работоспособность расширения обеспечивается путем предоставления пользователю новой версии.
Конфигурируемость: Исходный код расширения открыт (публичный репозиторий на GitHub). Продукт распространяется в виде подключаемого расширения (.cfe); при необходимости возможна доработка под задачи заказчика.
