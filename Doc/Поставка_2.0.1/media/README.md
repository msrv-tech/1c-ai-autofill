# Скриншоты для руководства пользователя

Разместите в этой папке изображения (скопируйте из `main/docs/media/` или создайте).

## Используемые в руководстве

| Файл | Описание |
|------|----------|
| `extensions-list.png` | Форма списка расширений (Настройки → Администрирование → Расширения) |
| `nomenclature-card.png` | Карточка номенклатуры с ссылками «Заполнить ИИ» и «Настройки» |
| `gitsell-registration.png` | Форма регистрации Gitsell (Device Flow) |
| `settings-form.png` | Форма настроек расширения |

## Дополнительно для сертификации 1С:Совместимо (п. 8.11.5)

| Файл | Описание |
|------|----------|
| `extension-path-1.png` | Путь к расширениям: Настройки → Администрирование |
| `extension-path-2.png` | Путь к расширениям: Печатные формы, Отчеты и обработки → вкладка Расширения |
| `security-profile-settings.png` | Настройки профиля безопасности (для режима п. 2.3.1) |
| `extension-file-dialog.png` | Диалог выбора файла при нажатии «Подключить» |
| `security-mode-warning.png` | Предупреждение о безопасном режиме (снятие галки, п. 2.3.2) |
| `extension-update.png` | Форма списка расширений с кнопкой «Обновить из файла» |
| `extension-disable.png` | Форма списка расширений со снятой галкой использования |
| `extension-delete.png` | Форма со стрелкой на кнопке удаления расширения |
