Краткая информация о расширении
----------------------------------
Расширение предназначено для автоматической генерации описания номенклатуры с помощью нейросетевых моделей (ИИ). На форму элемента справочника "Номенклатура" добавляется возможность заполнения описания по наименованию и реквизитам товара.

Расширение разработано для конфигураций "1С:Розница" и "1С:Управление нашей фирмой" (УНФ). Требуется поддержка расширяемой конфигурации на актуальных редакциях.
Расширение имеет назначение "Дополнение" и не требует внесения изменений в типовую конфигурацию.

Важная информация
----------------------------------
Внимание!
Рекомендуемая к использованию версия технологической платформы "1С:Предприятие 8" определяется требованиями расширяемой типовой конфигурации, не ниже 8.3.24 в режиме совместимости.

Для работы расширения требуется API-ключ сервиса gitsell.ru или иного ИИ-провайдера, настраиваемого в форме расширения.
